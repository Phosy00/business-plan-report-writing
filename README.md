# business-plan-report-writing

A Claude skill for drafting, reviewing and finalising a university business or digital transformation plan report.

一个 Claude skill，用于撰写、审阅和定稿大学商业计划 / 数字化转型计划报告。

## What it covers / 内容

- Working rules: discuss before editing, keep the student's own text, separate inference from fact, honest AI declaration.
  工作规则：先讨论再修改，保留学生自己写的内容，区分推论和事实，如实声明 AI 使用。
- Report structure and common framework definitions (Rogers' four vision elements, TOWS, VRIO, KPI chain).
  报告结构和常用框架的定义（Rogers 愿景四要素、TOWS、VRIO、KPI 层级）。
- Evidence checks against primary sources.
  对照一手来源核查证据。
- Word count, including text inside figures.
  字数统计，包括图片里的文字。
- Harvard referencing in the Cite Them Right style.
  Cite Them Right 版 Harvard 引用格式。
- A final PDF checklist before submission.
  提交前的 PDF 检查清单。

## How to use / 使用方法

Copy `skills/business-plan-report-writing/SKILL.md` into your Claude skills folder, or upload it as a skill in Claude.

把 `skills/business-plan-report-writing/SKILL.md` 复制到 Claude 的 skills 文件夹，或者在 Claude 里作为 skill 上传。

Always follow your own course brief and marking criteria where they differ from this skill.

如果和你自己的课程要求或评分标准不一致，以课程要求为准。
